# Настройка логина через Telegram и панели разработчика

Вся конфигурация — в `index.html`, блок `CONFIG` (в начале `<script>`):

```js
var CONFIG = {
  botUsername: "",        // username бота без @ (для входа в браузере)
  statsEndpoint: "",      // URL Google Apps Script Web App
  adminIds: [],           // Telegram ID с доступом к панели, напр. [123456789]
  devSecret: "baha-dev",  // запасной вход: ...#dev=baha-dev
};
```

Пока поля пустые — приложение работает как раньше, события пишутся только
локально (в браузере), а дашборд показывает статистику этого устройства.

---

## 1. Хранилище статистики (Google Apps Script + Таблица)

1. Создайте Google-таблицу.
2. **Расширения → Apps Script**, вставьте содержимое `apps-script.gs`, сохраните.
3. **Deploy → New deployment → Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
4. Скопируйте URL вида `https://script.google.com/macros/s/XXXX/exec`.
5. Вставьте его в `CONFIG.statsEndpoint`.

События начнут падать в лист `events`, а дашборд — показывать агрегаты по всем
пользователям (вкладка «Глобально»).

## 2. Логин через Telegram

**В Telegram Mini App** логин автоматический (через `Telegram.WebApp`) — ничего
настраивать не нужно.

**В обычном браузере** нужен Login Widget:
1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. У него же: `/setdomain` → укажите домен сайта
   (например `zevs2018123-cloud.github.io`).
3. Впишите username бота в `CONFIG.botUsername` (без `@`).

После этого на стартовом экране в браузере появится кнопка «Log in with Telegram».

## 3. Доступ к панели разработчика

Панель видят только Telegram ID из `CONFIG.adminIds`.

Как узнать свой ID: войдите через Telegram — на стартовом экране в чипе аккаунта,
а также внутри панели показывается «ваш Telegram ID». Добавьте его в `adminIds`:

```js
adminIds: [123456789, 987654321],
```

Запасной вход (до настройки списка или для отладки): открыть ссылку с хэшем
`#dev=baha-dev` (значение из `CONFIG.devSecret`). Рекомендуется сменить секрет.

## Что попадает в воронку

Шаги дашборда (уникальные пользователи на каждом этапе):

`app_open → start_click → view_map → module_open → quiz_start →
module_complete → view_final → cta_fxpro`

Плюс разбивка по модулям: сколько открыли, сколько прошли, средний % правильных.

## Приватность

- В Mini App сохраняются публичные поля Telegram (id, username, имя). Токены и
  личные данные не собираются.
- Гостям (без логина) присваивается анонимный локальный id.
- Проверка прав на панель — клиентская (для внутренней аналитики этого
  достаточно). Не храните в таблице ничего чувствительного.
